# クリスマス特集 2026｜デザイン確認用

添付の構成案2枚と「施策シート_株式会社アペル御中 - 1015@ご確認事項.csv」を基に作成した、レスポンシブなHTMLデザイン案です。

## 確認方法

- `index.html`：ブラウザで開けるページ本体。CSS・JavaScript・画像は相対パスで同梱。
- `design-desktop.png`：PC版全体（1440px幅）。
- `design-mobile.png`：スマートフォン版全体（390px幅）。
- `design-cover.png`：PC版ファーストビュー。
- `design-mobile-cover.png`：スマートフォン版ファーストビュー。

HTTPで確認する場合は、このディレクトリで `python3 -m http.server 8001 --bind 127.0.0.1` を実行してください。追加の依存関係・インストール・ビルドは不要です。

## デザイン方針

深いボルドー、アイボリー、控えめなゴールドを用い、冬の温もりと贈りものの特別感を表現しています。写真を大きく使う導入から、早期注文・配送確認・商品選びへと進める構成です。

## 構成案の反映

1. キービジュアル：クリスマスフラワーコレクション2026。
2. 早期クーポン：ページ上部に配置。
3. お届け案内：上部に集約。日程の詳細は同じブロック内で展開。本文途中の独立した配送セクションは削除。
4. 昨年のクリスマスで選ばれたギフト8選：資料の掲載順を反映。順位番号・ランキング見出しなし。8番目はパナッシュ（W67-H52）／レッド108本。
5. ディズニー特集。
6. ダーズンローズ特集。
7. 刻印・リングケース特集。
8. よくある質問：締切・ラッピング・名入れ・eギフト。
9. 関連コラム：花のプレゼント14選、プレゼント選び、ダーズンローズ。
10. eギフト：特集本文の最下部に配置。
11. サイト共通ランキング・商品検索・フッター。

構成案1枚目に合わせ、独立したイントロ・ページ内ナビ・本文途中の配送詳細・締めの独立セクションは削除しました。

各コレクションはビジュアルと既知の商品導線を中心としたデザインです。資料にある各4商品の完全な内訳は未提供のため、存在が確認できない商品・価格は補っていません。正式リスト受領後、各4商品のカード・リンクを反映する前提です。店舗共通ランキング・商品検索・フッターをeギフトの後に配置しています。共通ランキングは表示サンプルであり、正式な店舗全体の集計順位ではありません。

## 動作する部分

- ページ内リンク、ページ上部へ戻るボタン。
- 商品検索、商品案内ダイアログ。
- お気に入り登録・一覧。ブラウザのローカルストレージに保存。
- FAQ開閉、クーポン・各特集・記事の確認用ダイアログ。
- 日本時間でのお急ぎ便表示切り替え。`?date=2026-12-20` で非表示、`?date=2026-12-21` で表示を確認可能。クリスマス当日を過ぎると非表示になります。日付パラメータはレビュー用です。
- マウス・キーボード操作、Escapeでダイアログを閉じる操作、動きを減らす設定に対応。

## 正式素材・確認が必要な点

- 参考URL：https://www.amorosa-shop.jp/f/christmas （ユーザー提供の過去ページ。計測クエリを除いたURLを記録）。現行環境からの取得はネットワークポリシーにより403。過去ページの画面・正式素材・共通パーツとの直接照合は未完了です。必要なホスト www.amorosa-shop.jp と amorosa-shop.jp を環境の許可ドメインのドラフトに追加済みですが、保存のみでは実行環境に反映されません。環境設定で確認・保存しPublishする必要があります。
- 過去ページは見た目の参考として扱い、セクション順は構成案1枚目を優先しています。
- AMOROSAのブランド名に更新しました。現在はテキスト表記であり、店舗の正式なロゴ画像ではありません。
- 写真2点は生成したデザイン用画像です。実商品の形状・仕様を示すものではなく、ディズニーの公式画像でもありません。公開前に承認済みの実商品写真へ差し替えてください。
- 正式な各4商品の内訳、商品番号、価格、商品URL、eギフト対象商品、関連記事URL、レビュー掲載の可否。
- クーポンコード・適用条件・取得リンク。11月30日以降のクーポン掲載終了は本番側で設定する想定です。
- 未確定のお届け日程、お急ぎ便を12月21日以降に表示する提案の最終合意。
- FAQのラッピング・メッセージ・名入れは商品ごとに確認する案内とし、無料対応など未確認の条件を断定していません。
- canonical・構造化データは正式URLと商品データの確認後に本番側で設定してください。
