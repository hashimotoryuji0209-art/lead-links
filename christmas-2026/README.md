# クリスマス特集 2026｜デザイン確認用

添付の構成案2枚と「施策シート_株式会社アペル御中 - 1015@ご確認事項.csv」を基に作成した、レスポンシブなHTMLデザイン案です。

## 確認方法

- ルートの `Christmas-2026-PC.zip` をダウンロードして解凍し、`index.html` をダブルクリックしてください。
- CSS・JavaScriptを埋め込んだ単体HTMLです。インストールやサーバー起動は不要です。
- 商品写真はAMOROSA公式の画像配信元を参照します。閲覧時にはインターネット接続が必要です。
- ソースを直接確認する場合は、このディレクトリで `python3 -m http.server 8001 --bind 127.0.0.1` を実行できます。

## 実商品画像への差し替え

ギフト8選の全8商品について、公式商品ページのタイトルと `og:image` を照合して画像URLを採用しました。画像URLと公式商品ページは [assets/image-sources.json](assets/image-sources.json) に記録しています。

- 商品カード・商品ダイアログ・共通ランキングの表示サンプル・各特集・関連記事の画像を公式商品写真に差し替えました。
- キービジュアルにも実商品の写真を使用し、生成したバラの写真2点は最新版から除外しました。
- リングケースの特集画像には、公式の過去クリスマスページでリングケースとして掲載されているフォーエバーラブの写真を使用しています。
- 2番目の商品名を公式表記の「ダイヤモンドローズ ラブハート／ブライトレッド」に修正しました。
- 商品ダイアログから正しい公式商品ページへ移動できます。価格・在庫は公式ページで確認する案内にしています。

現行クラウド環境から公式サイトのHTMLは取得できますが、画像配信元 `mdrn0087.itembox.cloud` への接続は403で拒否されています。商品画像のファイル取得・見た目の最終確認・画像を埋め込んだオフライン版とPDFの再出力は未完了です。許可ドメインのドラフトには追加済みで、環境設定での保存・Publishが必要です。PC用HTMLは公式画像を直接参照する方式に更新しています。

以前のPDFとPNGは生成した仮写真のままになるため、最新版のファイル一覧とZIPから除外しました。公式画像取得後に再生成する予定です。以前のコミット履歴には旧版が残っています。PCでHTMLを開ける場合は、画像を読み込んでからブラウザの印刷機能でPDF保存することもできます。

## デザイン方針

深いボルドー、アイボリー、控えめなゴールドを用い、冬の温もりと贈りものの特別感を表現しています。写真を大きく使う導入から、早期注文・配送確認・商品選びへと進める構成です。

## 構成案の反映

1. キービジュアル：クリスマスフラワーコレクション2026。
2. 早期クーポン：ページ上部に配置。
3. お届け案内：上部に集約。日程の詳細は同じブロック内で展開。本文途中の独立した配送セクションは削除。
4. 昨年のクリスマスで選ばれたギフト8選：資料の掲載順を反映。順位番号・ランキング見出しなし。8番目はパナッシュ（W67-H52）／レッド108本。
5. ディズニー特集。
6. ダーズンローズ特集。
7. 刻印・リングケース特集。
8. よくある質問：締切・ラッピング・名入れ・eギフト。
9. 関連コラム：花のプレゼント14選、プレゼント選び、ダーズンローズ。
10. eギフト：特集本文の最下部に配置。
11. サイト共通ランキング・商品検索・フッター。

構成案1枚目に合わせ、独立したイントロ・ページ内ナビ・本文途中の配送詳細・締めの独立セクションは削除しました。

各コレクションはビジュアルと既知の商品導線を中心としたデザインです。資料にある各4商品の完全な内訳は未提供のため、存在が確認できない商品・価格は補っていません。正式リスト受領後、各4商品のカード・リンクを反映する前提です。店舗共通ランキング・商品検索・フッターをeギフトの後に配置しています。共通ランキングは表示サンプルであり、正式な店舗全体の集計順位ではありません。

## 動作する部分

- ページ内リンク、ページ上部へ戻るボタン。
- 商品検索、商品案内ダイアログ。
- お気に入り登録・一覧。ブラウザのローカルストレージに保存。
- FAQ開閉、クーポン・各特集・記事の確認用ダイアログ。
- 日本時間でのお急ぎ便表示切り替え。`?date=2026-12-20` で非表示、`?date=2026-12-21` で表示を確認可能。クリスマス当日を過ぎると非表示になります。日付パラメータはレビュー用です。
- マウス・キーボード操作、Escapeでダイアログを閉じる操作、動きを減らす設定に対応。

## 正式素材・確認が必要な点

- 参考URL：https://www.amorosa-shop.jp/f/christmas 。過去ページのHTMLと8商品の個別商品ページを取得・照合済み。構成の順序は構成案1枚目を優先しています。
- AMOROSAはテキスト表記で、店舗の正式なロゴ画像への置き換えは未実施です。
- 各コレクションの正式な4商品、掲載価格、関連記事URL、レビュー掲載の可否は確認が必要です。
- 共通ランキングは表示サンプルです。実際の集計順ではありません。
- クーポンコード・適用条件・取得リンク。11月30日以降の掲載終了は本番側で設定する想定です。
- 未確定のお届け日程、お急ぎ便を12月21日以降に表示する提案の最終合意。
- FAQのラッピング・メッセージ・名入れは商品ごとの確認を促し、未確認の料金や条件を断定していません。
- canonical・構造化データは正式URLと商品データの確認後に本番側で設定してください。

## 検証済み

Chromiumで1440pxと390pxの表示、ギフト8商品の描画、検索結果、お気に入りの登録・表示、FAQの開閉、クーポン案内、Escape操作、お急ぎ便の表示境界を確認しました。390px表示の横はみ出し・JavaScriptエラーはありません。公式画像への差し替え後は、8商品の画像URLと公式ページの `og:image` の一致を確認しています。現行クラウド環境からの画像本体の読み込み・実画像でのスクリーンショット確認は通信制限により未完了です。
