# lead-links

## クリスマス特集 2026 デザイン案（公式商品画像版）

- [PC用HTML（ZIP）をダウンロード](Christmas-2026-PC.zip?raw=true)
- [HTML・CSS・JavaScriptと制作メモ](christmas-2026/)
- [公式商品画像の参照元一覧](christmas-2026/assets/image-sources.json)

ZIPを保存・解凍し、`index.html` をダブルクリックしてください。インストールやサーバー起動は不要です。**商品写真の表示にはインターネット接続が必要です。**

構成案1枚目とヒアリングCSVを反映したデザイン案です。商品写真はAMOROSA公式の商品ページと照合した実画像のURLに差し替えました。共通ランキングは表示サンプルです。

現在のクラウド環境では画像配信元への接続が制限されているため、画像の埋め込みとPDF・PNGの再生成は保留中です。旧版のPDF・PNGは生成写真のままになるため、最新版の一覧から除外しました。詳細は [制作メモ](christmas-2026/README.md) を参照してください。
